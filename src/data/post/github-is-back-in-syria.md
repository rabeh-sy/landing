بعد سنوات من القيود والعقوبات، أعلنت GitHub عن توسيع وصول المطورين في سوريا إلى جميع خدماتها، بما في ذلك المستودعات الخاصة والخطط المدفوعة وGitHub Copilot. هذه الخطوة التاريخية تُعيد الثقة بأن الإبداع والتعاون البرمجي لا يجب أن تحدّه السياسة أو الجغرافيا.

# GitHub يُتيح وصولاً أوسع للمطورين في سوريا بعد رفع قيود التجارة

أعلنت GitHub في مقال نُشر بتاريخ **4 سبتمبر 2025** أن تخفيف العقوبات الأميركية وقيود التصدير على سوريا سمح بعودة الوصول إلى الخدمات الخاصة والمدفوعة للمطورين السوريين، لا سيما في المحافظات مثل حلب وحمص ودمشق وجميع أنحاء البلاد.

---

##  الخلفية والرؤية

منذ أكثر من أربع سنوات، رفعت GitHub شعارًا جوهريًا:  
> يجب أن يتمتع جميع المطوّرين بحرية استخدام GitHub، أينما كانوا.

ظلت خدمات التعاون في المشاريع مفتوحة المصدر والمستودعات العامة متاحة دومًا، كما يُظهر ذلك **GitHub Innovation Graph**، وهو مجموعة بيانات مفتوحة تعرض ملخصًا لمساهمات المطورين السوريين في مستودعات عامة.

---

##  التغييرات الجديدة

نتيجة للتغييرات الحكومية، ستُستعاد الآن الوظائف الكاملة لحسابات المطورين السوريين، بما في ذلك الوصول إلى **GitHub Copilot** والخدمات المدفوعة والخاصة. هذه التحديثات جارية ومن المتوقع أن تبدأ في الوصول إلى المستخدمين خلال **الأسبوع المقبل**.

تُقدّر GitHub المجهودات التي بذلها المطوّرون السوريون في الدعوة إلى هذا التغيير، وتؤكد التزامها بأن تكون "بيتًا للمطورين" الذين يحثهم شغفهم للابتكار والتعلّم والمشاركة، ضمن إطار الامتثال القانوني الدولي.

---

##  التزام GitHub الدائم

GitHub لطالما دافعت عن توسيع وصول المطورين في المناطق الخاضعة للعقوبات الأميركية، إذ نجحت سابقًا في الحصول على ترخيص من **OFAC** لاستعادة الخدمات السحابية لجميع المستخدمين في إيران، بما يشمل الحسابات الفردية والمؤسساتية، المجانية والمدفوعة.

علاوة على ذلك، توفّرت خدمات GitHub (خصوصًا المستودعات العامة والخاصة) بشكلٍ جزئي أو كلي للمستخدمين في كوبا، رغم العقوبات، وواجهت GitHub طلبات استئناف عديدة بسبب تقييد الحسابات في مناطق مثل سوريا. في عام 2022، عُدل وضع 120 حسابًا سوريًا بعد استئناف، في حين تم رفض 6 فقط.

---

## الخلاصة

GitHub تخطو خطوة مهمة نحو تعزيز الشمولية الرقمية للسوريين في مجال تكنولوجيا المعلومات والبرمجيات، وتؤكد أن حرية الوصول والتعاون لا يجب أن تُقيَّد بالجغرافيا أو السياسة. هذه المبادرة ليست مجرّد فائدة فردية، بل إنّها تُشكل بارقة أمل تسهم في بناء المستقبل التقني لسوريا.
